# Roblox Flight Script

Fly V4 is a client-side Roblox flying script and flight controller for use in your own Roblox experience. It lets players toggle flight, steer with normal movement controls, and rise or descend using keyboard inputs.

## Install

1. Open your experience in Roblox Studio.
2. In Explorer, go to `StarterPlayer > StarterPlayerScripts`.
3. Add a `LocalScript` and paste in the contents of `StarterPlayerScripts/FlyingController.client.lua`.
4. Start a play test.

## Use

1. Press **F** to start flying.
2. Use the normal movement controls to steer.
3. Hold **Space** to rise or **Left Control** to descend.
4. Press **F** again to stop flying.

This script runs on the client. For a live experience where flight affects gameplay, validate permissions and movement on the server.
